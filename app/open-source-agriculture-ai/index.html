The complete path

From a labelled pair to one bounded result

The browser sends one of two included audio-and-image pairs. The server accepts the files as real transport, but the current adapters interpret only exact fixture hashes.

  1. 1
    Match the fixture

    The deterministic speech and vision adapters return fixed transcript and image cues only for the bundled files. Unknown media receives zero confidence.

  2. 2
    Retrieve approved evidence

    The pipeline searches a small local knowledge file built from cited ICAR and IRRI material. It does not query an open web index or AIKosh.

  3. 3
    Generate within the boundary

    The default path is deterministic. An optional local Llama path can synthesize the English summary and select approved citations, while reviewed application copy controls the Odia guidance and safe action.

  4. 4
    Validate or stop

    Unknown citations, pesticide or fungicide instructions, invalid output, or confidence below 0.72 trigger the safe fallback and a KVK or agricultural extension referral.

Proof boundary

What this agriculture AI project proves

It proves an end-to-end, locally runnable pattern for grounded and uncertainty-aware agricultural triage. A reviewer can reproduce the supported and uncertain fixture paths, inspect the retrieved sources, and see where the system refuses to continue.

It does not prove
  • interpretation of arbitrary farmer speech or photos
  • a confirmed crop-disease diagnosis
  • agronomic accuracy or field readiness
  • AIKosh, Bhashini, messaging, mandi, or subsidy integrations

Reproduce it

Run the repository in one command

Clone the project on a machine with Python 3.11 or newer. No paid API or cloud credential is needed for the deterministic demo.

git clone https://github.com/iamaanahmad/Krishi-Vani-AI.git
cd Krishi-Vani-AI
./demo.sh

The design choice

The limits are part of the result

Many AI-in-agriculture projects lead with the range of tasks they hope to cover. Krishi-Vani starts with a smaller question: can one local-language crop-triage path show its evidence, refuse unsafe output, and remain easy to inspect? Today, the repository answers that question for two labelled fixtures. The next credible step is held-out media evaluation, not a wider claim.
