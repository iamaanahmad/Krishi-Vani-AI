Krishi-Vani AI — current challenge scope

Theme: Agriculture and Rural Innovation

Problem: An Odia-speaking rice farmer needs a safe, understandable first step when a leaf symptom is unclear.

Current prototype: Two labelled audio-and-image fixture pairs demonstrate one cited, non-chemical observation step or a KVK/extension escalation. The default path is deterministic and offline. A verified optional Ollama path uses local Llama 3.2 1B for grounded English synthesis and approved citation selection; reviewed application wording supplies Odia guidance and the safe action.

Current limits: The repository does not include real speech recognition, real image classification, external dataset integrations, model-generated Odia, agronomic accuracy evidence, field validation, messaging channels, mandi prices, or subsidy guidance. Arbitrary farmer media is accepted by the API contract but is not interpreted.

The broader multilingual assistant was the initial concept. It is not the shipped product described by this repository.
